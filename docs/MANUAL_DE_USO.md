**Material de onboarding para usuários**  
**Versão do manual:** 1.0  
**Atualizado em:** 31/05/2026

## 1. Apresentação

O NCProgrammers CRM é uma plataforma de atendimento multicanal. O sistema reúne conversas, contatos e histórico de atendimento em um único ambiente, permitindo que a equipe organize a operação por filas e acompanhe cada cliente até a resolução.

Os recursos disponíveis para cada pessoa dependem do perfil de acesso:

| Perfil | Recursos principais |
| --- | --- |
| Usuário | Dashboard, atendimentos e contatos |
| Administrador | Todos os recursos do usuário, além de canais, painel de atendimentos, relatórios, usuários, filas, mensagens rápidas, chatbot, etiquetas, horário de atendimento, configurações, campanhas e API |

> Alguns recursos dependem da configuração feita pelo administrador e dos canais contratados pela empresa.

## 3. Primeiro Acesso

### 3.1 Entrar no sistema

1. Acesse o endereço informado pela sua empresa.
2. Informe seu e-mail.
3. Informe sua senha.
4. Clique em **Login**.

Ao entrar pela primeira vez, permita as notificações do navegador. Elas avisam quando chegam novas mensagens de clientes.

### 3.2 Alterar seus dados

1. Clique no botão com suas iniciais, no canto superior direito.
2. Selecione **Perfil**.
3. Atualize nome, e-mail ou senha.
4. Clique em **Salvar**.

### 3.3 Definir seu status

No menu do usuário, selecione:

| Status | Quando usar |
| --- | --- |
| **Online** | Enquanto estiver disponível para atender |
| **Offline** | Ao pausar ou encerrar seu expediente |

Antes de sair do sistema, revise seus atendimentos em aberto e altere o status para **Offline**.

## 4. Navegação Geral

O botão de menu fica no canto superior esquerdo. O menu lateral recolhe automaticamente para liberar espaço na tela.

Na barra superior você encontra:

| Item | Finalidade |
| --- | --- |
| Sino de notificações | Exibe mensagens novas e clientes pendentes na fila |
| Indicador de status | Mostra se seu usuário está online ou offline |
| Botão com suas iniciais | Abre perfil, status e opção **Sair** |
| Alternância de tema | Ativa ou desativa o modo escuro |

## 5. Rotina Rápida do Atendente

Use esta sequência durante a operação:

1. Entre no sistema e deixe seu status como **Online**.
2. Abra **Atendimentos**.
3. Verifique os tickets pendentes. Eles aparecem destacados e podem exibir a quantidade de mensagens não lidas.
4. Clique no ícone verde **Atender** para assumir um ticket pendente.
5. Leia o histórico antes de responder.
6. Envie a resposta e, quando necessário, aplique etiquetas ou atualize a carteira do contato.
7. Use **Transferir** se outro usuário ou fila precisar continuar o atendimento.
8. Clique em **Resolver** quando a solicitação estiver concluída.
9. Ao final do expediente, revise os tickets em aberto e deixe seu status como **Offline**.

## 6. Dashboard

O **Dashboard** apresenta indicadores da operação. Use os filtros de data e filas e clique em **Atualizar**.

### Indicadores disponíveis

| Indicador | O que representa |
| --- | --- |
| Total Atendimentos | Quantidade total de atendimentos no período |
| Ativo | Atendimentos iniciados pela equipe |
| Receptivo | Atendimentos iniciados pelo cliente |
| Novos Contatos | Contatos criados no período |
| TMA | Tempo médio de atendimento |
| Tempo Médio 1ª Resposta | Tempo médio até a primeira resposta |

Também são exibidos gráficos por canal, por fila, evolução por período e performance dos usuários.

## 7. Atendimentos

O módulo **Atendimentos** concentra a rotina de conversas com clientes.

### 7.1 Entender a lista de tickets

Cada item da lista mostra o cliente, a última mensagem, o canal, a conexão utilizada, o número do ticket, o usuário responsável e a fila.

| Situação | Significado |
| --- | --- |
| Pendente | Aguardando alguém da equipe assumir |
| Aberto | Em atendimento |
| Resolvido | Atendimento finalizado |
| Ícone de robô | Chatbot interagindo com o cliente |
| Contador sobre o avatar | Mensagens ainda não lidas |

### 7.2 Pesquisar e filtrar tickets

Use a busca para localizar um atendimento. No botão de filtro avançado, é possível selecionar:

- filas;
- tickets abertos, pendentes ou resolvidos;
- somente tickets com mensagens não lidas;
- somente tickets sem usuário atribuído.

Administradores também podem ativar **Visualizar Todos**.

### 7.3 Assumir um atendimento pendente

1. Abra **Atendimentos**.
2. Localize o ticket pendente.
3. Clique no ícone verde **Atender**.
4. Aguarde a abertura da conversa.

Se a conversa já estiver atribuída a outra pessoa, transfira o ticket de forma explícita quando necessário.

### 7.4 Enviar mensagens

Digite no campo de mensagem e pressione `Enter` ou clique no ícone de envio.

Recursos disponíveis no rodapé do chat:

| Recurso | Como usar |
| --- | --- |
| Arquivo | Clique no clipe e selecione os documentos ou mídias |
| Colar imagem | Cole uma imagem no campo e confirme o envio na prévia |
| Emoji | Clique no ícone de emoji |
| Áudio | Com o campo vazio, clique no microfone; cancele ou envie ao terminar |
| Videoconferência | Clique no ícone de vídeo para gerar e enviar um link |
| Assinatura | Ative o seletor para incluir seu nome nas mensagens |
| Mensagem rápida | Digite `/` ou clique no ícone de mensagem rápida |

Para anexos, respeite os limites informados pela tela. O sistema permite múltiplos arquivos e exibe um aviso quando o tamanho aceito é ultrapassado.

### 7.5 Usar mensagens rápidas

1. No campo de mensagem, digite `/`.
2. Selecione uma resposta da lista ou continue digitando a chave cadastrada.
3. Revise o texto preenchido.
4. Envie a mensagem.

### 7.6 Responder, encaminhar ou apagar mensagens

Abra o menu de uma mensagem para acessar as ações disponíveis:

| Ação | Comportamento |
| --- | --- |
| Responder | Cita uma mensagem anterior na nova resposta |
| Encaminhar | Envia a mensagem para outro contato |
| Selecionar mensagens | Permite encaminhar até 10 mensagens juntas |
| Apagar | Remove mensagem enviada pela equipe quando permitido pelo canal |

O sistema impede a exclusão de mensagens com mais de 5 minutos do envio. Alguns canais também limitam as ações disponíveis.

### 7.7 Agendar uma mensagem

1. Com o ticket aberto, clique no ícone de agendamento no cabeçalho da conversa.
2. Informe a data e a hora.
3. Digite a mensagem.
4. Envie.

A mensagem ficará identificada como agendada no histórico.

### 7.8 Transferir, retornar à fila, resolver ou reabrir

No cabeçalho do chat, use o botão **Resolver** e sua seta lateral:

| Ação | Quando usar |
| --- | --- |
| Resolver | Finaliza o atendimento concluído |
| Fila | Retorna o ticket aos pendentes |
| Transferir | Envia o atendimento para uma fila e, opcionalmente, um usuário |
| Reabrir Ticket | Reabre um atendimento já resolvido |

Na transferência, primeiro escolha a fila. Se selecionar um usuário, o sistema atribui o ticket diretamente a ele. Sem usuário definido, o ticket retorna como pendente na fila escolhida.

### 7.9 Consultar e atualizar o contato durante o atendimento

Na lateral direita do chat, você pode:

- visualizar nome, telefone e e-mail;
- editar o contato;
- abrir os logs do atendimento;
- incluir ou remover etiquetas;
- definir uma carteira responsável;
- consultar informações adicionais.

## 8. Contatos

O módulo **Contatos** reúne os registros de clientes. A lista pode conter dados de WhatsApp, Instagram e Telegram, conforme os canais utilizados.

### 8.1 Criar um contato

1. Acesse **Contatos**.
2. Clique em **Adicionar**.
3. Informe nome, número com DDI e DDD e, se disponível, e-mail.
4. Use **Adicionar Informação** para incluir observações estruturadas.
5. Clique em **Salvar**.

### 8.2 Editar ou excluir

Use os ícones na coluna **Ações**:

- lápis: editar;
- lixeira: excluir.

Confirme exclusões somente após verificar se o cadastro correto foi selecionado.

### 8.3 Iniciar atendimento ativo

1. Localize o contato.
2. Clique no ícone do canal desejado.
3. Escolha a conexão que realizará o envio.
4. Clique em **Iniciar**.

Se já existir atendimento em curso, o sistema oferecerá a opção de abrir o ticket existente.

### 8.4 Importar e exportar

No menu do botão **Adicionar**, estão disponíveis:

| Opção | Uso |
| --- | --- |
| Importar do WhatsApp | Sincroniza contatos já existentes nas conexões de WhatsApp |
| Importar `.CSV` | Importa arquivo com as colunas `Nome; Numero` |
| Exportar | Baixa a lista de contatos |

Na importação por `.CSV`, também é possível aplicar etiquetas e definir uma carteira para os contatos importados.

## 9. Recursos Administrativos

Esta seção é destinada a usuários com perfil **Administrador**.

### 9.1 Canais

Use **Canais** para cadastrar e monitorar conexões.

#### Adicionar canal

1. Acesse **Canais**.
2. Clique em **Adicionar**.
3. Selecione o tipo: **WhatsApp**, **Telegram** ou **Instagram Oficial**.
4. Informe um nome único para identificar a conexão.
5. Para Telegram, informe o token.
6. Se desejar, cadastre uma mensagem de despedida usando as variáveis `{{name}}`, `{{greeting}}` e `{{protocol}}`.
7. Clique em **Salvar**.

#### Conectar WhatsApp

1. Localize o canal.
2. Clique em **Novo QR Code** ou **QR Code**.
3. No celular, abra o WhatsApp e acesse a opção de aparelhos conectados.
4. Leia o QR Code exibido.
5. Aguarde o status **Conectado**.

#### Conectar Instagram Oficial

1. Crie e salve um canal **Instagram Oficial**.
2. Clique em **Conectar**.
3. Autorize o acesso na janela oficial da Meta.
4. Aguarde o status **Conectado**.

O sistema não solicita nem armazena a senha da conta no fluxo oficial.

Em cada canal, o administrador também pode associar um bot, editar dados, desconectar ou excluir a conexão. Evite excluir canais que já tenham histórico de atendimentos.

### 9.2 Painel Atendimentos

O **Painel Atendimentos** apresenta uma visão operacional dos tickets. Use filtros de período e filas e escolha uma visualização:

- por usuário;
- por usuário sintético;
- por filas;
- por filas sintético.

### 9.3 Relatórios

O menu **Relatórios** oferece:

| Relatório | Filtros principais |
| --- | --- |
| Contatos | Período de criação |
| Contatos por Etiqueta | Uma ou mais etiquetas |
| Contatos por Estado | Um ou mais estados, identificados pelo DDD |
| Resumo Atendimentos Usuários | Período dos atendimentos |

Após gerar um relatório, use **Imprimir** ou **Excel** quando disponível.

### 9.4 Usuários

Use **Usuários** para cadastrar a equipe e administrar acessos.

1. Clique em **Adicionar**.
2. Informe nome, e-mail e senha.
3. Selecione **Usuário** ou **Administrador**.
4. Clique em **Salvar**.

Na lista, use:

| Ícone | Função |
| --- | --- |
| Gestão de filas | Define quais filas o usuário poderá acessar |
| Lápis | Edita dados e perfil |
| Lixeira | Exclui o usuário |

### 9.5 Filas

Filas organizam os atendimentos por equipe, assunto ou setor.

1. Acesse **Filas**.
2. Clique em **Adicionar**.
3. Informe o nome.
4. Marque **Ativo**.
5. Clique em **Salvar**.

Depois, associe as filas aos usuários no módulo **Usuários**.

### 9.6 Mensagens Rápidas

Mensagens rápidas são respostas padronizadas usadas no atendimento.

1. Acesse **Mensagens Rápidas**.
2. Clique em **Adicionar**.
3. Informe uma chave curta para pesquisa.
4. Digite a mensagem.
5. Clique em **Salvar**.

Durante o atendimento, a equipe pode localizar a mensagem digitando `/`.

### 9.7 Chatbot

O módulo **Chatbot** permite criar fluxos visuais de atendimento automático.

#### Criar um fluxo

1. Acesse **Chatbot**.
2. Clique em **Adicionar**.
3. Informe a descrição.
4. Use **Número para Teste** enquanto estiver validando o fluxo. Com esse campo preenchido, a automação ficará limitada ao número informado.
5. Marque **Ativo** quando apropriado.
6. Clique em **Salvar**.
7. Clique no ícone de diagrama para abrir o editor visual.

No editor visual, configure etapas, mensagens, interações, condições e destinos. Os destinos podem direcionar para outra etapa, uma fila ou um usuário. Também existem opções de tempo de espera, tentativas e parâmetros conforme o tipo de etapa.

Um fluxo também pode ser editado, duplicado ou excluído. Após validar, associe-o a um canal ou selecione-o em **Configurações** como fluxo ativo.

### 9.8 Etiquetas

Etiquetas ajudam a classificar contatos.

1. Acesse **Etiquetas**.
2. Clique em **Adicionar**.
3. Informe o nome e escolha a cor.
4. Marque **Ativo**.
5. Clique em **Salvar**.

As etiquetas podem ser aplicadas durante o atendimento, na importação de contatos, nos relatórios e na seleção de públicos para campanhas.

### 9.9 Horário de Atendimento

Configure o funcionamento para cada dia da semana:

| Tipo | Comportamento |
| --- | --- |
| Aberto | Estabelecimento aberto o dia todo |
| Fechado | Estabelecimento fechado o dia todo |
| Horário | Funcionamento limitado aos intervalos informados |

Também cadastre a **Mensagem de Ausência** enviada fora do horário configurado. A mensagem de ausência é enviada após o encerramento do atendimento automático.

### 9.10 Configurações

Em **Configurações**, o administrador controla regras gerais:

| Configuração | Efeito |
| --- | --- |
| Não visualizar tickets já atribuídos a outros usuários | Restringe a visualização ao responsável e administradores |
| Não visualizar tickets no ChatBot | Oculta da equipe os tickets em interação com o bot |
| Forçar atendimento via Carteira | Direciona contatos com carteira somente aos responsáveis definidos |
| Fluxo ativo para o Bot de atendimento | Define o fluxo padrão para novos atendimentos |
| Ignorar Mensagens de Grupo | Impede abertura de tickets para grupos |
| Recusar chamadas no WhatsApp | Recusa chamadas automaticamente e permite definir uma mensagem de resposta |

### 9.11 Campanhas

Campanhas realizam envios programados. As mensagens são enviadas em horário comercial e dias úteis.

#### Criar campanha

1. Acesse **Campanha**.
2. Clique em **Adicionar**.
3. Informe nome, data e hora de início, canal de envio e intervalo entre envios.
4. Se desejar, anexe uma mídia.
5. Preencha a composição de até três mensagens.
6. Revise a prévia.
7. Clique em **Salvar**.

#### Selecionar contatos e programar envio

1. Na lista, abra os contatos da campanha.
2. Clique em **Incluir Contatos**.
3. Filtre por estado, etiqueta ou carteira.
4. Clique em **Gerar**, selecione os contatos e clique em **Adicionar**.
5. Volte para a lista de campanhas.
6. Clique em **Programar Envio**.

Uma campanha pode ser cancelada durante o agendamento ou processamento. Revise sempre o público e a mensagem antes de programar.

### 9.12 API

O menu **API** configura integrações com sistemas externos.

1. Clique em **Adicionar**.
2. Informe o nome da integração.
3. Selecione a conexão de WhatsApp usada para envio.
4. Se necessário, informe URLs de webhook para status da sessão e status das mensagens.
5. Informe o token de autenticação que será enviado no cabeçalho dos webhooks.
6. Clique em **Salvar**.

Na lista, é possível copiar o token, editar, gerar um novo token ou excluir a configuração.

> Gerar um novo token interrompe integrações que ainda utilizem o token anterior. Atualize o sistema integrado imediatamente após a renovação.

## 10. Boas Práticas

- Mantenha seu status atualizado.
- Leia o histórico antes de responder.
- Use etiquetas padronizadas para facilitar relatórios e campanhas.
- Resolva tickets concluídos para manter a fila organizada.
- Ao transferir, selecione a fila correta e, quando necessário, o usuário responsável.
- Confirme o destinatário antes de encaminhar mensagens.
- Revise contatos e conteúdo antes de programar campanhas.
- Não compartilhe senhas ou tokens de API.
- Evite excluir canais, usuários, filas ou contatos sem confirmar o impacto.
